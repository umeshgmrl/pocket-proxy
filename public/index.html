Let’s connect your Mac.
Approve HTTPS once, then start interception. We’ll check each step for you.

  
Checking your setup…

  
01 · HTTPS SETUP
Set up HTTPS
Checking whether this Mac trusts the app’s certificate…
macOS will ask you to approve this app’s personal HTTPS certificate. Importing and verification happen automatically. No website is contacted for this check.

  
Need help? Keychain fallback
If macOS could not finish approval, we can import the exact public certificate and open Keychain Access.
Find the certificate below, double-click it, expand Trust, and set Secure Sockets Layer (SSL) to Always Trust. Close the window to save, then click Verify HTTPS.

Another Pocket Proxy installation may have a different certificate. We verify this exact one. Existing certificates and trust are preserved.

  
02 · MAC PROXY
Start interception
Once HTTPS is verified, select your network and start interception.
macOS may request administrator approval for network settings. Quitting or stopping capture restores saved settings.

  
Connecting a terminal or a specific app?
Some clients ignore macOS proxy settings. Configure their proxy and certificate explicitly.

  
Coverage: HTTP/HTTPS in apps that use the proxy. Certificate-pinned apps and HTTP/3 may need application-specific configuration. WebSockets pass through; their frames are not inspected. Existing connections may need a browser or app restart.
